Request elevated access

Use this form to request temporary elevated access to a production workspace.

Before you begin

Elevated access is granted for a fixed window and is revoked automatically when that window closes. Your manager is notified when the request is filed, not when it is approved. Every request must cite the reference code RX-4471 so the security team can reconcile it against the current audit cycle. Requests filed without it are held in a queue that is reviewed manually, which usually adds several business days.

Scope of access

Elevated access covers read and write on workspace records. It does not extend to billing, to tenant configuration, or to the audit log itself. If your work requires any of those, file a separate request with your security partner rather than broadening this one.
